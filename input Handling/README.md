# User Details Form (React)

This is a simple React form application that collects **user details** and displays them after submission.

---

## 🚀 Features

- Controlled inputs using `useState`
- Single input handler for all fields
- Form data stored in an object
- Conditional rendering to show submitted data
- Beginner-friendly structure

---

## 🛠️ Concepts Used

- React `useState`
- Event handling (`onChange`, `onClick`)
- Object state
- Conditional rendering (`&&`)
- Controlled components

---

## 📋 Form Fields

- Name
- Email
- Mobile Number

---

## 🧠 How It Works

1. User enters data in input fields  
2. `inputHandler` updates state dynamically using input `name`
3. On clicking **Submit**, data is displayed below the form
4. Data is shown only when `show` state is `true`
